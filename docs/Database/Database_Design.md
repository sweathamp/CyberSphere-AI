# CyberSphere Database Design

## 1. Overview

CyberSphere uses PostgreSQL as its primary relational database. The database is designed to store user information, conversations, messages, uploaded cybersecurity artifacts, analysis results, generated reports, and AI agent execution history.

The design follows a relational model to maintain data consistency, establish clear relationships between entities, and support future scalability.

## 2. Entities

### Users

Stores registered user information and authentication-related data.

### Conversations

Represents individual conversations created by users.

### Messages

Stores messages exchanged between users and CyberSphere within a conversation.

### Uploaded Files

Stores metadata associated with cybersecurity files uploaded by users.

### Analysis Results

Stores the results generated by specialized cybersecurity agents.

### Reports

Stores metadata and references for reports generated by CyberSphere.

### Agent Runs

Tracks individual AI agent executions, their status, execution time, and summarized results.

## 3. Relationships

- One user can have multiple conversations.
- One conversation can contain multiple messages.
- One user can upload multiple files.
- A conversation can contain multiple uploaded files.
- An uploaded file can have multiple analysis results.
- A user can generate multiple reports.
- A conversation can generate multiple reports.
- A conversation can contain multiple agent runs.
