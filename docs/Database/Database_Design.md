# CyberSphere Database Design

## Overview

CyberSphere uses PostgreSQL as its primary relational database.

The database stores user accounts, chat sessions, uploaded files, analysis results, generated reports, and AI agent activity.

The database is designed to maintain user history, support multiple AI agents, and enable future scalability without modifying the existing architecture.

## Initial Entities

- Users
- Chat Sessions
- Messages
- Uploaded Files
- Analysis Results
- Reports
- Agent Logs
